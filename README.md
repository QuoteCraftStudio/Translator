## Overview

QuoteCraft Translator is a browser-based interface for translating and speaking between two languages. It is designed around a two-sided conversational layout.

## Highlights

- Choose languages for each side of the conversation.
- Enter or speak text using the controls provided.
- View translation responses in a two-language interface.
- Use device-supported speech features when available.

## Get started

Open [`Translator.html`](./Translator.html) in a compatible browser to explore the source application. This is a web project; an installer is not supplied by GitHub Releases here.

> **Compatibility:** Translation and microphone features depend on browser permissions, supported languages, and the services used by the source file. Do not assume offline support.
