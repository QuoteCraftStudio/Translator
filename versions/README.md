## Android APKs and signing

Android packages are **not** placed in this public source repository. Signed historical APKs and comparison checksums are indexed within the owner's **private** `QuoteCraft-App-Archives/Translator/README.md`. APKs with different signing certificates cannot simply update each other.

**Security:** The October 7 source ZIP contains signing credentials; it must not be committed to public GitHub or uploaded unencrypted. The original Drive copy stays intact until a recoverable encrypted archive is confirmed.

## Scope of this archive

- All 14 HTML files are preserved under dates without changing their application code.
- This index does not assert that any snapshot works, fixes a defect, or is newer by application version.
- No live website, release workflow, permissions, or application behavior has been changed.
